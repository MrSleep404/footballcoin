# 公式预测与校准

本文档记录「统计公式基线」的定义、当前参数、已跑出的验证结果，以及赛果更新后的校准流程。目标是让公式成为可复现、可审计的 `baseline`，而不是替代大模型。

## 1. 定位与原则

- 公式负责给出**可复算的基础概率**，同一组输入永远得到同一个结果。
- 大模型负责公式无法表达的部分（新闻、动机、轮换意图），并做**有限幅度**修正。
- 市场赔率**不参与计算**，只在生成后用于对照，避免公式退化成市场解释器。
- 校准目标不是「贴近市场」，而是「概率与实际频率一致」（校准度）和「Brier 分数更低」。

## 2. 公式

### 2.1 基础期望进球

```text
λ主 = (主队主场场均进 × 客队客场场均失 / 联赛场均进) × 主场系数 × 各修正因子
λ客 = (客队客场场均进 × 主队主场场均失 / 联赛场均进 / 主场系数) × 各修正因子
```

样本不足时先向联赛均值收缩：

```text
场均平滑 = (场均 × 样本场次 + k × 联赛均值) / (样本场次 + k)
```

主客场拆分样本少于 3 场时，回退到赛季总场均。

### 2.2 比分概率

```text
P(i, j) = Poisson(λ主, i) × Poisson(λ客, j)   i, j ∈ [0, 8]

P(主胜) = Σ P(i > j)
P(平局) = Σ P(i = j)
P(客胜) = Σ P(i < j)
```

### 2.3 修正因子

| 因子 | 计算方式 | 当前取值 |
|---|---|---|
| 主场系数 HA | 常数 | 1.07 |
| 状态 | `1 + (近 5 场场均净胜球 − 赛季场均净胜球) × 0.03` | 限 0.88~1.12 |
| 排名 | `1 ± 排名差 × 0.004` | 限 ±10% |
| 交手 | `1 ± (近 N 次主队胜率 − 0.5) × 0.1` | 限 ±5% |
| 伤病 | 按伤缺人数分级 | 0 人 1.00；1~2 人 0.97；3~4 人 0.94；5 人以上 0.90 |
| 天气 | 降水 >60% ×0.95；风速 >30 ×0.97；气温 <0°C ×0.98 | 乘积 |
| 赛程 | 休息 ≤2 天 ×0.92；≤3 天 ×0.95 | 前后 4 天内有其他赛事 |

## 3. 当前参数与验证结果

当前参数：`k = 8`，`HA = 1.07`，`λ` 限制在 0.25~3.0。

对 2026-11-28 至 12-03 的 59 场联赛回算：

| 指标 | 结果 |
|---|---|
| 公式 vs 模型 平均最大偏差 | 9.29pp |
| 公式 vs 市场 平均最大偏差 | 10.97pp |
| 与模型偏差 >8pp 的场次 | 26 场 |
| 公式最高概率 ≥90% 的场次 | 0 场 |

调整前（k=3、无 λ 上限）：平均偏差 13.32pp / 15.19pp，3 场 ≥90%。

### 3.1 已知失真场次

| 比赛 | 公式 | 模型 | 市场 | 问题 |
|---|---|---|---|---|
| 汉堡 vs 拜仁 | 27/24/48 | 12/16/72 | 10/14/76 | 收缩过强，低估强弱差 |
| 弗赖堡 vs 莱比锡 | 66/17/17 | 36/26/38 | 35/25/40 | 主队主场 5 场场均 2.8 球，波动被放大 |
| 巴黎 vs 洛里昂 | 41/30/29 | 75/17/8 | 78/14/8 | 与上一条相反，收缩抹平差距 |

结论：`k` 是当前最主要的敏感参数，调小会过度自信，调大会抹平强弱差，必须用赛果校准。

## 4. CSV 文件

文件：`docs/formula-review.csv`（UTF-8 带 BOM，Excel 可直接打开）。

| 列 | 含义 |
|---|---|
| `date` / `league` / `home` / `away` | 比赛基本信息 |
| `formula_home_draw_away` | 公式概率，格式 `主/平/客` |
| `model_home_draw_away` | 大模型概率 |
| `market_home_draw_away` | 市场去水概率 |
| `formula_pick` / `model_pick` / `market_pick` | 各自概率最高项 |
| `actual_score` / `actual_outcome` | 赛果与胜平负（未开赛为空） |
| `formula_hit` / `model_hit` / `market_hit` | 是否命中（1/0，未开赛为空） |
| `formula_brier` / `model_brier` / `market_brier` | 三项 Brier 分数（越低越好） |
| `lambda_home_away` | 公式的 λ 主/客 |
| `generated_at` | 预测生成时间，用于版本追踪 |

## 5. 校准流程（赛果更新后执行）

1. 拉取最新数据：

```powershell
.\update-data.cmd
```

2. 生成/刷新 CSV 与指标：

```powershell
node scripts/formula-review.mjs
```

3. 读取脚本输出：
   - 命中率对比：公式 / 模型 / 市场
   - Brier 对比
   - 校准分桶：公式最高概率 50-60、60-70、70-80、80+ 各档的实际命中率

4. 按以下顺序调参并重跑：

```powershell
node scripts/formula-review.mjs --k=5
node scripts/formula-review.mjs --k=8 --ha=1.05
```

5. 每次调参后记录：参数、样本场次、Brier、校准分桶偏差，追加到本文档「6. 调参记录」。

### 5.1 校准判据

- **校准度**：最高概率 70-80% 的场次，实际命中率应在 70-80% 区间；若系统性低于该区间，说明过度自信。
- **区分度**：Brier 分数下降，且不低于随机猜测（约 0.667）。
- **稳定性**：样本 ≥50 场后再下结论，少于 30 场只看趋势。

## 7. 决策规则

赛果累计到 50 场后，按以下规则决定公式的去留：

| 条件 | 决策 |
|---|---|
| 公式 Brier 低于市场 5% 以上 | 作为 `baseline` 接入提示词，大模型只做 ±5pp 修正 |
| 公式 Brier 介于模型与市场之间 | 作为参考输入写入提示词，不主导最终概率 |
| 公式 Brier 比市场高 10% 以上 | 放弃公式，保留纯模型判断，仅保留伤病修正规则 |

接入方式：公式结果写入 `baseline` 字段，提示词中把「先算 baseline」改为「使用给定 baseline，只输出 contextAdjust 与理由」。

## 8. 注意事项

1. 公式依赖 `stats` 字段，历史数据（2026-11-26 11:44 之前）没有该字段，无法回算。
2. 欧冠样本每队只有 4~5 场，主客场拆分 2~3 场，收缩后区分度低，不宜单独用欧冠校准。
3. 伤病字段只覆盖赛前 3 天内的比赛，远期快照没有名单，公式会按 0 人处理。
4. 所有因子权重均为初值，未经历史回测；本文档的调参记录是唯一依据。
